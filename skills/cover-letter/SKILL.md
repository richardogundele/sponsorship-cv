# Cover letter

Write a cover letter that shows one employer, clearly and briefly, why this person fits this job. Every claim must come from what the user has told you.

## What you need

1. **The user's CV** or a summary of their experience.
2. **The job description.**
3. **Optional but helpful:** the employer's name, the hiring manager's name, and anything the user knows or likes about the organisation.

If the CV or job description is missing, ask for it before writing.

## Workflow

1. **Pick the 3 requirements that matter most** in the advert: the ones the employer repeats, lists first or calls essential.
2. **Find the user's best proof for each** in their CV: a specific role, project or result. If the proof is thin, ask one short question rather than guessing.
3. **Write the letter** using the structure below.
4. **Finish with a check list** (see Output).

## Structure

- **Greeting:** "Dear [hiring manager's name]," if known, otherwise "Dear Hiring Manager,".
- **Opening (2 to 3 sentences):** the exact job title, and a specific reason this person wants this role at this employer. Use what the user told you about the organisation; if they gave nothing, base it on the advert itself. No clichés like "I am writing to express my interest".
- **Evidence (2 short paragraphs):** take the top requirements one by one and back each with a concrete example and, where the user gave one, a result or number.
- **Close (2 sentences):** what they would bring in the first months, and a simple, confident line about discussing it further.
- **Sign-off:** "Kind regards," and the user's name.

Keep it to **250 to 400 words** and one page. Use UK spelling and a professional, warm tone that sounds like a real person, not a template.

## Right to work and sponsorship

Only mention immigration status if the user asks you to. If they do, keep it to one factual sentence using exactly what they tell you. Never suggest hiding or misstating it.

## Rules

- **Never invent** experience, results, qualifications, reasons for applying or facts about the employer.
- Use the advert's language where it is true for the user.
- Don't repeat the CV line by line; pick the strongest evidence and explain why it matters for this job.
- Do not promise an interview, sponsorship or a visa outcome.

## Output

1. The finished letter in clean plain text.
2. **Check before you send:** names, placeholders such as `[result]` to fill, and any claim the user should double-check.
